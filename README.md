# 🎬 Movie Recommendation System

A Movie Recommendation System built with Python that suggests movies to users based on their preferences using three different Machine Learning techniques — Content-Based Filtering, Collaborative Filtering (SVD), and a Hybrid approach.

## ✨ Features

- ✅ **Content-Based Filtering** — Recommends movies similar to a given title using TF-IDF and Cosine Similarity on movie genres and titles
- ✅ **Collaborative Filtering** — Recommends movies based on user rating patterns using SVD (Matrix Factorisation) built with pure NumPy
- ✅ **Hybrid Recommender** — Combines both methods with weighted blending for better and more diverse results
- ✅ **Exploratory Data Analysis** — Generates 7 visualisation charts (rating distribution, genre distribution, heatmaps, etc.)
- ✅ **Model Evaluation** — Computes RMSE, MAE, Precision@K, Recall@K using 3-Fold Cross Validation
- ✅ **No heavy dependencies** — No scikit-surprise required, runs on pandas + numpy + scikit-learn only
- ✅ **Auto dataset download** — MovieLens 100K downloaded automatically on first run

## 🧠 How Each Recommender Works

### 1. Content-Based Filtering
Each movie is converted into a text "soup" combining its title and genres. TF-IDF vectorisation turns this into numerical vectors, and Cosine Similarity finds the closest matching movies.

```
Toy Story  →  "toy story animation children comedy"
Aladdin    →  "aladdin animation children comedy musical"
                ↑ high similarity → recommended
```

### 2. Collaborative Filtering (SVD)
Builds a User × Movie rating matrix and applies Singular Value Decomposition to find hidden patterns. The reconstructed matrix predicts ratings for unseen movies — highest predicted ratings are recommended.

```
         Titanic  Toy Story  Matrix  Inception
User 42:    5        ?         4        ?
                     ↑ SVD predicts 4.3 → recommended
```

### 3. Hybrid Recommender
Combines Content-Based similarity scores and Collaborative predicted ratings, normalises both to a 0–1 scale, and blends them:

```
Hybrid Score = 0.4 × Content Score + 0.6 × Collaborative Score
```
