# 🎬 Movie Recommendation System

A Movie Recommendation System built with Python implementing three recommendation strategies on the **MovieLens 100K** dataset — Content-Based Filtering, Collaborative Filtering (SVD), and a Hybrid approach.

---

## 📌 Techniques

| # | Technique | Algorithm | Key Library |
|---|-----------|-----------|-------------|
| 1 | **Content-Based Filtering** | TF-IDF + Cosine Similarity | scikit-learn |
| 2 | **Collaborative Filtering** | SVD (Matrix Factorisation) | NumPy |
| 3 | **Hybrid Recommender** | Weighted Blend (CB + CF) | both |

## 🧠 How It Works

### 1. Content-Based Filtering
Each movie is converted into a text "soup" from its title and genres. TF-IDF vectorisation turns this into numerical vectors, and Cosine Similarity finds the most similar movies to a given title.

```
Toy Story  →  "toy story animation children comedy"
Aladdin    →  "aladdin animation children comedy musical"
                ↑ high similarity → recommended
```

### 2. Collaborative Filtering (SVD)
Builds a User × Movie rating matrix and decomposes it using Singular Value Decomposition to discover hidden patterns (latent factors). The reconstructed matrix fills in missing ratings — movies with the highest predicted rating for a user are recommended.

```
         Titanic  Toy Story  Matrix  Inception
User 42:    5        ?         4        ?
                     ↑ SVD predicts 4.3 → recommended
```

### 3. Hybrid Recommender
Combines the top results from both methods, normalises their scores, and blends them with configurable weights (default: 40% Content-Based + 60% Collaborative) for more accurate and diverse recommendations.
